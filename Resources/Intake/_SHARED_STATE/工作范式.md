# 资源库整理工作范式

> 2026-08-12 固化。下次接手直接从这里读，不必重新摸索。

## 一、核心原则

1. **物理目录只按创作者分一层**：`R:\Media\创作者\<创作者>\`。真人/2D/3D/体位/服装/平台/画质一律只做 Stash 标签，不建物理顶层分类。
2. **创作者 = 频道主（拍摄者/账号主），不是出镜者**。男性约多位女性的频道归到该男性名下，带 `男主频道`+`多女出镜` 标签；能具名的出镜女性作为附加 Performer 挂同一场景（Stash 支持一场景多 Performer），不具名的用描述性标签承载。
3. **任何批量操作先出 CSV 映射预览，执行后核对总数与总字节**。基准：**2,552 文件 / 844,902,505,772 bytes**。
4. **不确定就标注，不要猜**。置信度分级写进台账，`disambiguation` 字段留痕。

## 二、身份识别三条路（按可靠性排序）

### 1. 画面水印 —— 最可靠

目录名经常是伪装（已证实：`梦比优斯奥特曼（日配）`→MyElla、`宇宙英雄奥特曼`→RecklessDome、
`电化学_金属腐蚀…`→梅麻呂3D），但转载者通常保留原作者烧录的水印。

**方法**：抽帧拼接触表读图。
- 认目录归属：`rm-contactsheet.ps1`（4 视频 × 4 帧 = 4×4 网格）
- 逐文件判定：`rm-indexsheet.ps1`（每文件 1 帧，25 个一页）
- 确认具体行为：`rm-verify.ps1`（指定场景 ID 密集抽帧）

**关键实现细节**：抽帧时必须统一画布尺寸
（`scale=W:H:force_original_aspect_ratio=decrease,pad=...`），否则同目录内分辨率不一致
会让 ffmpeg 的 image2 解复用器在尺寸变化处中断，只拼出前几格 —— 这个坑踩过。

**必须区分创作者水印与转载渠道水印**：
`@FLshe11` `@SFJT68` `@hmfl8` `@zupi8888` `52ywy.com` `5snn.com` `9P3456.com` 是电报群和盗版站。

### 2. 作品名联网反查 —— 对日系同人有效

`淫乱爆乳女教師 MOVIE版` → 梅麻呂3D；`chocolat まいとれい` → アトリエこぶ；
`動画置場 北上さん…` → フリム。用 WebSearch 搜作品原名即可。

### 3. 文件名文本 —— 最不可靠但可批量

⚠️ **推特转载文件名里的 `@账号` 多数是蹭流量的引流号**：

| 形态 | 含义 | 处理 |
|---|---|---|
| `RT_@X - 正文…` | X 是转推原作者 | ✅ |
| `女主@X` | 明确标注的出镜者 | ✅ |
| 正文里的中文名 | 主体人物 | ✅ |
| 末尾成串裸 @ `@A @B @C` | 引流互推 | ❌ |
| `📷：@X` | 摄影师 | ❌ 角色非创作者 |

## 三、标签体系

`R:\Resources\Tools\rm-tagmap.ps1` 是单一事实来源。改它 → 跑 `rm-import.ps1` 全库重打。

- 关键词匹配对**完整相对路径**（含子目录名），不只文件名
- 技术类标签（4K/2K/1080P/720P、竖屏/横屏、高帧率、时长分档）**从 Stash 文件元数据推导**，不靠文件名猜
- 每个标签带 booru 英文别名，中英文都能搜

**部位词 ≠ 行为**，已拆四层：`屁眼`(anus) / `毒龙`(rimjob) / `肛塞`(butt_plug) / `肛交`(anal)。
`肛交` 可靠关键帧确认（插入状态持续存在）。

**`内射` 用关键帧验证已实测不可行，别再试**：
1. 射精只有几秒，均匀抽帧必然错过
2. 更致命的是**大量文件末尾是盗版站广告片尾**（msnapk.com / macxv9.com / 淘精TV / 91TV影城
   整屏广告，可长达数十秒），所以"末段 20%"抽到的是广告不是正片结尾

本库 `内射` 保持文件名判定即可——中文转载标题会明写「中出/内射」，是发布者自己标注的，
比画面推断更可靠。已建 `片尾广告` 标签备用。

## 四、下载期流水线

```powershell
cd R:\Resources\Tools
.\rm-register.ps1 -Url "..." -Password "..." -Note "..."   # 登记，钉住链接/时间/密码
.\rm-process.ps1 -Batch <ID>                                # 解压去伪装 → 快照 → 归类 → 入库
.\rm-import.ps1                                             # Stash 扫描 → 打标 → 归属
```

去伪装两层：magic bytes 判真实类型，认不出用 ffprobe 兜底（裸 H.264 码流、冷门容器都能救）。
密码本自动累积。解不开的进 quarantine，不静默丢弃。

## 五、PowerShell 踩过的坑

1. **别用 `$pid` 当变量名** —— 是自动变量（当前进程ID），赋值不生效，会把进程号当 ID 写进数据库
2. **`[ordered]@{}` 重复键是解析期错误** —— 整个文件加载失败、变量全变 null，且不明显报错
3. **`{2,+4}` 不是合法格式符** —— 用 `-f` 格式化时会抛异常
4. **沙箱会拦 `Remove-Item` + 变量路径** —— 改用 `[System.IO.File]::Delete()` / `[System.IO.Directory]::Move()`
5. **Stash 任务队列是串行的** —— 长任务（PHash）会阻塞扫描，需先 `stopJob`
