## 必须遵守的约定

1. **物理目录只按创作者分一层。** 真人/2D/3D/体位/服装/平台/画质一律只做 Stash 标签，不建物理顶层分类目录。
2. **创作者 = 频道主（拍摄者/账号主），不是出镜者。** 男性约多位女性的频道归到该男性名下（`91大屌哥`/`Timepasserby`/`Svj798ds`，带 `男主频道`+`多女出镜` 标签）；能具名的出镜女性作为**附加 Performer** 挂同一场景，不具名的用描述性标签承载。
3. **目录名可能是伪装。** 已知案例：`梦比优斯奥特曼（日配）`→MyElla、`宇宙英雄奥特曼`→RecklessDome、`电化学_金属腐蚀…`→梅麻呂3D。判定优先级：画面水印 > 作品名联网反查 > 文件名文本。
4. **区分创作者水印与转载渠道水印。** `@FLshe11`/`@SFJT68`/`@hmfl8`/`@zupi8888`/`52ywy.com`/`5snn.com`/`9P3456.com` 是电报群和盗版站，不是创作者。
5. **部位词 ≠ 行为。** `屁眼`(部位) / `毒龙`(rimjob) / `肛塞`(道具) / `肛交`(明确性交) 四层分开，别混用。
6. **任何批量操作先出映射预览，执行后核对 2,552 个文件 / 844,902,505,772 bytes 不变。**

## Stash API 速查

```powershell
$u='http://127.0.0.1:9999/graphql'
function GQ($q,$v){ $b=@{query=$q}; if($v){$b.variables=$v}
  $r=Invoke-RestMethod -Uri $u -Method Post -ContentType 'application/json' -Body ($b|ConvertTo-Json -Depth 12 -Compress)
  if($r.errors){ throw ($r.errors|ConvertTo-Json -Depth 6) }; $r.data }

# 全部场景+路径+元数据
GQ '{findScenes(filter:{per_page:-1}){scenes{id files{path width height frame_rate duration}}}}'
# 批量加标签（每批 ≤200）
GQ 'mutation($ids:[ID!],$t:[ID!]){bulkSceneUpdate(input:{ids:$ids,tag_ids:{ids:$t,mode:ADD}}){id}}' @{ids=$ids;t=@($tagId)}
# 批量加创作者
GQ 'mutation($ids:[ID!],$p:[ID!]){bulkSceneUpdate(input:{ids:$ids,performer_ids:{ids:$p,mode:ADD}}){id}}' @{ids=$ids;p=@($perfId)}
```

⚠️ 两个坑：
- **别用 `$pid` 当变量名**，那是 PowerShell 自动变量（当前进程ID），赋值不生效，会把进程号当 ID 写进去
- **`[ordered]@{}` 里重复键是解析期报错**，整个文件加载失败、变量全变 null，且不会明显报错

## 分工建议

避免同时对**同一批场景**做 `bulkSceneUpdate`。按创作者目录或标签域切分，各改各的。
改 `rm-tagmap.ps1` 前先看对方是否也在改。
