## 五、执行步骤

### 步骤 1 —— 垃圾（零风险）

```powershell
$csv = Import-Csv "C:\Users\longm\Desktop\115-dedup\junk.csv"
Write-Output "待删 $($csv.Count) 个"
$ok = 0; $fail = @()
foreach ($r in $csv) {
  try { Remove-Item -LiteralPath $r.路径 -Force -ErrorAction Stop; $ok++ }
  catch { $fail += "$($r.路径) :: $($_.Exception.Message)" }
}
Write-Output "成功 $ok  失败 $($fail.Count)"
$fail | Select-Object -First 20
```

失败超过 50 个就停下来问用户。

### 步骤 2 —— 同名同大小（先抽查）

# 分批，每批 100 个，每批后报告

### 步骤 3 —— 归一化名（逐组看）

这层的判据是「去掉站点前缀/画质后缀/`(1)(2)` 序号后同名，且大小完全相同」。
典型情况是 `xxx.mp4`、`xxx(1).mp4`、`xxx(2).mp4` 三份同大小。

**把全部 301 组分批（每批 50 组）给用户过目**，确认一批删一批。

### 步骤 4 —— 目录包含（逐条确认）

只有 12 条，**每一条都要单独给用户确认**。确认时同时列出两个目录的文件名，让用户判断：

```powershell

Get-ChildItem $del -File | Select-Object Name, @{n='GB';e={[math]::Round($_.Length/1GB,2)}}
Get-ChildItem $keep -File | Select-Object Name, @{n='GB';e={[math]::Round($_.Length/1GB,2)}}
```
