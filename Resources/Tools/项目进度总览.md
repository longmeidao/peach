## 零、终态形态（2026-08-13 确立）

**最终落地是一个默认本地自托管、也能安全远程访问的网页应用，各终端都能访问。**
不是命令行工具集，不是 Stash 的附属品 —— Stash 只是其中一个数据源。

形态参考 **selfhost dashboard + RSS reader** 的设计语言：

```
┌─ 涌现推荐 ──────────────┐  ┌─ 追更看板 ───────────────┐
│ 说一句心情 → 出 5–8 个   │  │ 我关注的作者/厂牌有新东西 │
│ 本地/网盘/在线混排        │  │ 按来源分组，未读高亮      │
│ 一键打开 + 👍👎已看反馈   │  │ 参考 RSS reader 的已读模型 │
└────────────────────────┘  └─────────────────────────┘
┌─ 常用搜集站导航 ─────────┐  ┌─ 库存概览 ───────────────┐
│ 南+/司机社/f95zone/       │  │ 21 TB 分布、加工进度      │
│ rule34/pixiv/DLsite…      │  │ 缺口分 Top N             │
│ 参考 dashboard 的磁贴布局 │  │                          │
└────────────────────────┘  └─────────────────────────┘
```

### 四块功能

| 模块 | 内容 | 参考 |
|---|---|---|
| **涌现推荐** | 心情/关键词 → 候选，跨本地+网盘+在线 | 已有 `rm-suggest.py`，需 Web 化 |
| **追更看板** | 关注的作者/厂牌的更新流，未读/已读状态 | RSS reader（Miniflux / FreshRSS 的已读模型） |

| **库存概览** | 分布、加工进度、缺口清单 | Grafana 式面板，但要简单 |

**技术约束**：默认本机/LAN 部署；外部 connector 显式授权、控频并记录来源。媒体和行为数据

DDNS + 反向代理 + HTTPS，不能把应用端口直接裸露公网。

### 落地顺序

它决定了前面几期的产出格式：

- ledger.db 必须是**唯一真相源**，Web 端只读它，不再各自维护状态
- 追更结果要写进 `quest` 表并带「未读」标记，而不是打印到终端
- `rm-suggest.py` 的三通道逻辑要能被 HTTP 调用（先做成本地 API，再套界面）

**⚠️ 2026-08-13 更正优先级**（原写「第一~三期做完再开工」，是错的）：

四块功能里，**只有播放+埋点+反馈这个最小壳要立刻做**，其余三块照旧押后。
理由是判断 #18/#19：整套推荐的燃料是消费数据，而消费数据只能从带埋点的播放器里来。
现在 2,551 个 scene 里只有 5 个有播放记录 —— 反馈闭环是空的，
且只要消费还发生在 PotPlayer / 直接双击文件，它就会**永远**是空的。

标签可以边用边补，数据一天不采就永远缺一天。所以：

```
最小壳（第二期并行）：能播 + 埋点 sceneSaveActivity + 三个反馈按钮
完整界面（第四期）：  涌现磁贴 / 追更看板 / 站点导航 / 库存概览
```

后端以 ledger 为唯一真相源，经可替换 Media Engine 选择本地文件、Stash 或后续 native backend。
Stash GraphQL 只作过渡兼容层，不能再成为全局存储层。

## 一、这个项目到底在做什么

一句话：**把散在四处的 23 TB 资源，变成一个能按心情检索的库。**

拆开是四件事，它们是有依赖顺序的：

```
① 搞清楚口味      → 从浏览/搜索/关注记录反推，而不是凭空建标签
② 让库变得可见     → 23 TB 里 97% 原本是「有但看不见」
③ 去重与整理      → 重复、广告、无语义目录
④ 涌现推荐        → 说一句心情，从库里挑几个给你
```

## 四、方案迭代：被自己推翻的判断（31 条）

**这一栏是本项目最有价值的部分** —— 每一条都是「先有结论、后被实测打脸」。

### 最大的短板

**有消费记录的只有 5 条。** 浏览/搜索/关注反映的是「找」，不是「爱」—— 反复搜同一个东西 80 次，可能是极合口味，也可能是一直没找到。这两种在数据上无法区分，但推荐含义相反。

`rm-suggest.py` 的 `--like` / `--dislike` / `--seen` 是解决它的起点。**攒够约 200 条显式反馈，推荐质量会有质变。**

## 九、边界（全程遵守，未破例）

- 只动 `R:`、`%LOCALAPPDATA%\Stash`、账本产物；不碰 Disk 0 / LaCie / Xiaomi
- 不上传任何文件名 / 封面 / 指纹 / 媒体 / 浏览记录到第三方
- 联网仅限：按作品名查公开资料、调用各网盘自己的 API
- 网盘只做元数据操作和 seek 抽帧，不批量解压、不整文件下载
- 删除一律先出 CSV 再执行，全程留日志；批量操作后核对文件数与总字节
- Stash 仅绑 `127.0.0.1:9999`
- 账本与全部分析产物留在本地，不进同步盘
