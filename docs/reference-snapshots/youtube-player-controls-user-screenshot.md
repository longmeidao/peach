## Peach 主动保留的差异

- 不复制 YouTube 品牌、字幕、剧院模式和自动播放开关；没有真实能力就不画假按钮。
- 保留 Video.js、键盘前后跳转、画中画、全屏和真实清晰度菜单；控制栏不再重复画前后 10 秒按钮。
- 单一路源只显示实测分辨率或原画；`HD`／`4K` 只是当前媒体等级标记，不伪造可切换线路。
