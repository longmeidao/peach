## 可复用证据

在 1124×911 的桌面视口中，页面按以下阅读顺序排列，文档宽度 1109px，没有横向溢出：

1. 160px 圆形头像与名称、计数组成资料头。
2. 简介紧随资料头，正文最大宽度约 430px。
3. 外部链接使用 36px 高的横向胶囊按钮。
4. 关联艺人使用圆形头像加下方名称的横向滚动带。

6. 内容列表排在上述资料和筛选信息之后。

## Peach 复用与差异

- 女优、厂牌资料页采用“头像与名称 → 简介 → 链接 → 关联艺人 → 标签 → 视频／照片”的顺序。
- 关注页复用相同的信息层级：“标题 → 作者 → 状态、来源和标签 → 视频／图片 → 内容”。
- Beeg 当前 Reislin 页面只显示视频列表，没有可复核的照片切换；Peach 的视频／照片切换来自自身真实媒体数据，不宣称复制 Beeg 的不存在控件。
- Peach 保留自己的暗色变量、实体筛选、计数和操作语义，不复制 Beeg 品牌、关注按钮或外部商业链接。
- 用户提供的 Peach 详情截图明确了合集的适配方式：普通详情仍是左媒体、右信息，合集／Mix／分卷／播放列表／多媒体切换改为下方横向轨道，不使用原来的右侧竖向队列。
