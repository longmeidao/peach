# Windows 测试版

1. 下载 `Peach-<版本>-windows-x64.zip`，右键「全部解压」。保留整个 `Peach` 文件夹。
2. 双击 `Peach.exe`。浏览器会打开首次设置页。
3. 填入已有媒体文件夹的完整路径，选择访问范围与是否立即扫描，提交。设置完成后自动进入馆藏。

选择「只有这台电脑」时从 `http://127.0.0.1:<端口>` 打开；选择「同一局域网的设备」时，
其他设备从 `http://<设置的名字>.local:<端口>` 打开。Windows 首次询问防火墙权限时只允许
「专用网络」；不需要安装 Python、Git、Node 或 OpenSSL。局域网里有其他使用者时建议开启访问密码。
数据保存在当前用户的 `%LOCALAPPDATA%\Peach\peach-data`，和程序目录分开。

## 临时远程链接

配置页的「Cloudflare 临时链接」默认关闭。先在「访问设置」中设置访问密码，再启动链接；地址是 cloudflared 临时生成的随机 `https://<id>.trycloudflare.com`，不是直接打开 `https://try.cloudflare.com/`。关闭 Peach 或停止链接后，地址失效。

源码运行使用本机 HTTPS 与项目 CA；Windows 独立包使用回环 HTTP，外部访问仍由 Cloudflare 提供 HTTPS。独立包已附带经过 SHA-256 校验的 `cloudflared.exe`。如果页面提示连接失败，先检查防火墙或代理是否允许 cloudflared 出站 TCP/UDP `7844`；已经显示随机地址不代表边缘连接已经成功。

该功能面向临时预览，不是稳定域名、团队账号或 Cloudflare Access。不要把随机地址写入书签、文档或公开配置；不要在没有访问密码时绕过页面强行启动。

## 配置与反馈

- 页面右上角「设置」→「媒体文件夹与服务配置」，或托盘「配置 Peach」，可以修改媒体文件夹、端口并请求扫描。
- 保存配置会重新启动本机服务，正在播放的视频会中断；已有配置备份为 `config.previous.toml`。
- 配置页列出版本、数据目录和日志目录。反馈问题时写上版本、操作步骤、预期结果和实际结果；日志请先检查并移除个人路径与来源网址，不发送 `secrets` 目录或账本。
- 端口被占用时，退出占用该端口的其他程序后重试；修改端口时界面会检查冲突。
- 局域网地址解析不到时，确认两台设备在同一个网络、路由器没有开启客户端隔离，并检查 Windows 防火墙是否允许 Peach 的专用网络连接。
- 测试包没有代码签名。如果 Windows 提示未识别应用，请核对下载来自本项目 Release，并与 `SHA256SUMS.txt` 对照后再决定是否运行。

## 采集测试

1. 完成媒体扫描后，进入「数据管理」→「设置采集来源」。
2. 高清来源可能需要代理。在对应来源选「自定义代理」，填写该电脑可用的代理地址并保存；
   「系统代理」沿用电脑的代理设置（不支持 PAC），「应用直连」不使用应用代理。
3. 点击「检查连接」。DMM 分别检查页面与高清 CDN，图片检查会显示实际像素尺寸。
4. 在「高清封面」填入馆藏番号，点击「抓取封面」。任务只处理该番号；只有完整解码且
   像素面积更大的封面才替换，失败保留已有图片。相同成功结果在 24 小时内复用本机文件。
5. FC2 CLI 用户可在同页选择「粘贴 Cookie」或「导入文件」，二选一。文件支持 Netscape `.txt`。凭据保存于本机，
   「已保存」不表示会话有效；撤销后该来源的登录采集需重新提供 Cookie。

当前测试入口覆盖官方高清封面与 FC2 凭据配置。FC2 元数据批量采集、Javinizer-Go 的工具安装和
完整来源代理配置仍走各自 CLI；Instagram 自动头像、来源清单迁移、浏览器 Cookie 直接导入和
跨用户登录态验收尚未完成。请勿把 Cookie、带签名图片网址、`secrets` 或完整账本发送给测试者。

反馈时记录版本、操作系统、来源、连接方式、番号、状态与图片像素；不同电脑不共享 Cookie。

## 播放与更新

浏览器支持的 MP4 可以直接播放。转码、抽帧和缩略图需要 FFmpeg 与 ffprobe：安装后加入 PATH，或把两个程序放到数据目录下的 `tools\ffmpeg\bin`，退出并重新启动 Peach。

更新时先在托盘退出 Peach，再完整解压新版到新的程序目录。不要只替换 EXE；`_internal` 是程序的一部分。数据目录保留不动，重新启动会使用已有配置。

macOS 独立桌面包仍在开发，当前按 README 的源码安装流程使用。
